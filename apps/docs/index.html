Lexsys documentation

Registry-first React UI

Install editable components into your project with the Lexsys CLI. This site is a minimal docs shell — canonical specs live in the monorepo docs/ tree.

Quick start

Stable lane (0.1.0+ @ latest):

npx @dalexto/lexsys@latest init vite my-app
cd my-app
lexsys add button
lexsys add dialog

Preview lane (0.0.x @ next):

npx @dalexto/lexsys@next init vite my-app
