# Rule proposals (discussion before catalog)

One file per **candidate** rule. Each file is a **proposal to discuss**, not a decision.

| Step | Who |
| ---- | --- |
| Agent drafts proposal (za / protiv / pitanja) | Agent |
| You argue, add cases, change scope | You |
| Agree `NEED \| NO \| DEFER` | Both |
| Record in [RULES_CATALOG.md](../RULES_CATALOG.md) | Agent |

Next proposal file is created only after the previous row leaves `pending`.
